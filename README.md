# SokoHub — Products & Services Marketplace

SokoHub is a marketplace project designed to connect people who want to buy or sell products and offer or find services.

## Technologies

- **Frontend:** HTML, CSS and JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Version control:** Git and GitHub

## Project Structure

```text
soko hub/
├── Frontend/
│   ├── index.html
│   ├── script.js
│   └── style.css
├── Backend/
│   ├── api/
│   ├── config/
│   ├── public/
│   └── src/
├── database/
├── docs/
├── .gitignore
└── README.md
```

## Team Responsibilities

1. **Frontend development:** Website layout, styling, navigation and browser interactions.
2. **PHP backend development:** Server-side logic and API endpoints.
3. **Database and integration:** MySQL schema, database connectivity and feature integration.
4. **Coordination and testing:** GitHub workflow, code reviews, documentation and testing.

Team members should agree on individual responsibilities and support each other where needed.

## Collaboration Rules

- Keep `main` stable and working.
- Create a separate branch for each task.
- Commit changes with clear, descriptive messages.
- Push your branch to GitHub and open a pull request.
- Review changes before merging into `main`.
- Pull the latest changes before starting new work.
- Communicate before changing shared files or folder structures.
- Never commit passwords, private credentials or real user data.

## Development Setup

1. Install Git and a PHP development environment.
2. Install or configure MySQL.
3. Configure the PHP application to connect to MySQL using local environment settings.
4. Follow the project setup instructions agreed upon by the team.

## Project Status

The frontend starter files exist. The backend folder structure and database setup are being prepared. The redesigned frontend will be integrated after it is shared and reviewed by the team.
